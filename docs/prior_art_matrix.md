## The TRACEGUARD claim (deliberately narrow)

TRACEGUARD is, to our knowledge, the first fully open, preregistered evaluation that measures the **marginal monitoring value of authentic reasoning traces on genuinely executed agent trajectories** with:

1. exact state-based ground truth for unauthorized actions (no LLM judge, no authored transcripts),
2. within-episode paired evidence conditions (A vs C on the SAME trajectory) at a calibrated operating point,
3. token/length-matched noise (D) and cross-episode shuffled traces (E) to separate reasoning CONTENT from extra context,
4. family-level holdout + full environment-family shift set (RQ2),
5. a separate pre-action online experiment distinguishing detection from prevention (RQ4),
6. an explicit capability funnel (attack policy → attempted → succeeded) that separates agent capability from monitor quality.

"Potential contribution worth testing against prior art, not an automatic claim of novelty" — the matrix above is the test; if a reviewer identifies a study already doing all six, TRACEGUARD's contribution reduces to replication in an open-weight setting, which we will state plainly.
